## Antes de empezar

Arrancá el entorno elegido en la [guía de instalación](../installation/README.md).
Los enlaces de esta página abren documentación, no registros de tu instalación.

Un **Asset** es un recurso digital con revisiones y archivos. Un **Producto** define
lo que ofrecés; una **receta** describe cómo fabricarlo. **Quick Quote** prepara
una evaluación que podés formalizar en un **Quote**, el presupuesto. **Test Print**
permite probar una receta antes de promover explícitamente su resultado a stock.

## Un recorrido sugerido

Asset → Producto y receta → Quick Quote → Presupuesto → Pedido o proyecto →
Producción → Inventario y entrega.

Test Print es un recorrido de prueba de receta; no hace falta crear un presupuesto
para usarlo. Aprobar, convertir, producir y entregar son acciones explícitas
separadas: un paso no ejecuta silenciosamente los siguientes.

Estas guías reflejan pantallas existentes. Todavía no hay un tutorial completo
con datos precargados ni un modo demo instalable. Para una revisión más amplia,
seguí el [recorrido de pantallas](../development/frontend_prueba_manual_es.md).
Si algo no coincide con lo esperado, [contanos cómo reproducirlo](../installation/testing_es.md#reportar-un-problema).
