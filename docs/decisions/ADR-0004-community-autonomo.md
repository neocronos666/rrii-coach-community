# ADR-0004: Community autónomo

- Estado: aceptada; alcance revisado el 2026-10-17.
- Fecha original: 2026-07-28.

## Decisión

Este repositorio contiene RRII-Coach Community como producto independiente.
Sus flujos no dependen de servicios privados ni de claves para habilitar
capacidades. No se incorporan flags de distribución ni módulos desactivados.

## Consecuencias

Los cambios se evalúan contra el alcance funcional existente. La estabilización
no agrega infraestructura ni contratos para funcionalidades nuevas.
