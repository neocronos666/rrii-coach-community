# Glosario Community

- **Asset:** recurso digital reutilizable, separado del producto comercial.
- **Revisión:** versión numerada e histórica de un Asset o de un Quick Quote.
- **Producto y variante:** catálogo comercial y su configuración concreta.
- **Opción:** característica y valores permitidos para configurar un producto.
- **Receta:** pasos, dependencias, recursos e inputs para fabricar o preparar.
- **Costo técnico:** estimación conservada como snapshot, distinta del precio.
- **Markup:** porcentaje que se aplica al costo para obtener un precio sugerido.
- **Quick Quote:** cotización rápida con revisiones y formalización explícita.
- **Quote:** presupuesto con ítems técnicos y condiciones comerciales.
- **Pedido:** destino operativo de un presupuesto de un ítem.
- **Proyecto:** destino operativo que coordina varios componentes presupuestados.
- **Tarea:** objetivo productivo de un pedido o componente de proyecto.
- **Run:** intento real con resultados, consumos y máquina opcional.
- **Test Print:** prueba experimental de una receta completa, sin destino comercial.
- **Insumo:** recurso físico registrado con unidad base, compras y movimientos.
- **Reserva:** cantidad de insumo comprometida para una tarea.
- **Asignación:** cantidad de producto vinculada a un destino operativo.
- **Seña:** condición del presupuesto, fija o porcentual; no es un registro de cobro.
