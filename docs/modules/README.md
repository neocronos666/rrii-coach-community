# Módulos: uso y contratos

Las guías de interfaz describen recorridos reales; las de contrato explican reglas
y efectos de API. Los resultados de pruebas se atribuyen a cada ejecución y no
se deducen de la existencia de una guía. OpenAPI es el contrato técnico de rutas.
